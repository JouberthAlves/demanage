# Code of Conduct

## Our standard

deManage should remain a respectful and productive technical space. Contributors and maintainers are expected to focus criticism on the work, communicate in good faith, and protect user privacy.

Unacceptable behavior includes harassment, threats, discriminatory abuse, doxxing, publishing private data or credentials, deliberate disruption, spam, and knowingly misleading security or validation claims.

## Scope

This policy applies to issues, pull requests, reviews, project discussions, and other public deManage project spaces.

## Enforcement

Maintainers may edit, hide, lock, or remove content; reject contributions; or restrict participation when necessary to protect contributors and the project.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md).

For sensitive conduct concerns, contact the repository owner privately through GitHub.
