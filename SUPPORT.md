# Support

deManage is a personal/open-development project and does not provide a commercial support SLA.

## Bugs

When Issues are enabled, use the GitHub bug-report form with:

- commit or deployed revision;
- browser / operating system;
- affected frontend or backend component;
- reproduction steps using disposable data;
- sanitized logs when useful.

Do not post JWTs, cookies, recovery codes, database dumps, environment files, credentials, or personal financial data.

## Setup and self-hosting

Start with:

- [README.md](README.md)
- [plans.md](plans.md)
- [docs/](docs/)

For self-hosted deployments, include only sanitized deployment details needed to reproduce the problem.

## Feature requests

Use the feature-request form when Issues are enabled and explain the user problem first.

## Security

Do not report vulnerabilities in a public support thread. Follow [SECURITY.md](SECURITY.md).
